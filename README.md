# Networking Labs

## VLAN Router-on-a-Stick Lab

### Objective
Configure VLANs and allow communication between VLANs using Router-on-a-Stick.

### Technologies Used
- Cisco Packet Tracer
- VLANs
- 802.1Q
- Trunk Ports
- Inter-VLAN Routing

### Configuration
- Created VLAN 10 (HR)
- Created VLAN 20 (IT)
- Assigned access ports to VLANs
- Configured trunk connection between switch and router
- Configured router subinterfaces using 802.1Q encapsulation

### Verification
- Tested connectivity within VLANs
- Verified inter-VLAN communication using ping
- Troubleshooted VLAN assignment and routing issues

### Skills Practiced
- VLAN configuration
- Trunk configuration
- Router-on-a-Stick
- IP addressing
- Network troubleshooting
